# Nonogram 解题器的形式化与实现

## 框架选择

Nonogram（数织）求解的本质是**约束满足问题（CSP）**，更精确地说是**整数格点上的单调串约束系统**。选择理由：

- 每条线索（行/列的连续黑块长度序列）定义一个**正则语言** $\mathcal{L}_{c} \subseteq \{0,1\}^{n}$：块长固定、块间至少一个白格、两端可贴边。
- 全局面貌是 $\binom{H \times W \text{ 个布尔变量}}{}$ 上的合取约束，每条约束是正则语言成员关系。
- 判定性问题 `给定 nonogram 是否可解` 是 $\mathbf{NP}$-完全的（Ueda & Nagao 1996），所以我们不指望多项式算法，但**绝大多数实际谜题在"单线传播 + 有限分支"下即可解**。

`[另一解]` 也可放在**精确覆盖/整数规划**框架下（ILP with big-M 或 flow 约束），但那只在需要调用通用求解器时才有优势；手写解题器用 CSP 形态更直接。下文主用 CSP，交叉处标注 ILP 视角。

## 形式化陈述

**对象**：网格 $G \in \{0,1\}^{H \times W}$（1 = 黑）。

**线索**：对第 $r$ 行，给序列 $\rho_r = (a_1,\dots,a_k)$，$a_i \ge 1$；定义
$$
\mathcal{L}(\rho_r,n) = \Big\{ x \in \{0,1\}^{n} : x \text{ 中连续 1 段长度序列恰为 } \rho_r \Big\}.
$$
列同理得 $\kappa_c$。空线索 $\rho = ()$ 对应全零串，$\mathcal{L}((),n)=\{0^n\}$。

**约束**：
$$
\forall r: G_{r,\cdot} \in \mathcal{L}(\rho_r, W), \qquad \forall c: G_{\cdot,c} \in \mathcal{L}(\kappa_c, H).
$$

**目标**：判定集合 $\mathcal{S} = \{G : \text{上述全成立}\}$ 是否非空（可解性）；进一步，若 $|\mathcal{S}|>1$ 则称**多解**。

**关键不变量（要在实现中贯穿）**：每个格子三值状态 $\{0,1,?\}$，传播过程中维护的语义是
$$
\text{状态} \models (\text{该格在所有合法解中取该值}), \quad ? = \text{尚未确定}.
$$
任何一次赋值必须**保解**：赋值后 $\mathcal{S}' = \mathcal{S} \cap \{\text{该格}=v\} \neq \varnothing$。否则该赋值非法。

## 交叉论证：算法正确性 = 单调收缩 × 完备性分层

**视角 A（算子视角）**：单线传播是作用在 $D = \{0,1,?\}^{H \times W}$ 上的一个**单调收缩算子** $F$：$F(D) \subseteq D$，且 $D_1 \subseteq D_2 \Rightarrow F(D_1) \subseteq F(D_2)$。迭代 $F$ 到不动点 $F^*$。性质：

- 正确性：$F^*(D_0) \supseteq \mathcal{S}$（不漏解），因为每步只排除**必然不取该值**的格。这是**必要条件算子**。
- 不完备性：$F^*(D_0) \supset \mathcal{S}$ 可能严格成立——存在"看起来每格都可能，但全局不可解"的局面。这就是为什么非平凡谜题需要回溯。

**视角 B（决策树视角）**：把 $F^*$ 当预处理，然后在一棵**分支树**上搜索：节点选一个 $?$ 格假设为 0/1，递归。完全性由树穷尽 $D$ 的所有分支保证；正确性由每支的传播保解保证。搜索复杂度下界由 $\mathcal{S}$ 的结构决定，无一般多项式界（NP-完全已知）。

**交叉处的张力 `[待确认]`**：算子视角给"无解告警"的一个易错点——$F^*(D_0)$ 中出现**某条线无合法串**（$D$ 的该行约束不满足）时，能断定**当前分支**无解，但**不能断定原谜题无解**，除非当前分支是根。实现里必须把"分支可解性 vs 谜题可解性"分清，否则会把有解谜题误报无解。这是朴素实现中最常见的 bug 之一。

## 边界与反例先行

在写传播前先把这些情况钉死：

1. **空线索**：$\rho=()$，整行必须全 0。实现里要显式处理，别让 `k=0` 时循环体空转成"无约束"。
2. **满线索**：$\rho=(W)$，整行全 1；$a_i$ 之和 + $(k-1) > n$ 直接不可满足——**前置检查**放构造期，早失败。
3. **单元素**：$n=1$，$\rho$ 只能为 $()$ 或 $(1)$。
4. **退化多解**：$H=W=1$、无任何线索时 $\mathcal{S}=\{0,1\}$ 全部，二义。多解检测必须能返回它。
5. **传播的"假确定"反例**：构造一格行线索说必为 1、列线索说必为 0 的局面（矛盾）——正确实现应在赋列约束时发现该格已被定为 1 而冲突，而不是静默覆盖。
6. **对抗性规模**：单线传播在 $n$ 大时若用"枚举所有 $\mathcal{L}(\rho,n)$"会指数爆炸（$\mathcal{L}$ 大小是 $\binom{n-\sum a_i+1}{k}$ 量级）。反例：$n=100$、$\rho=(1,1,\dots,1)$ 有 ~$10^{29}$ 个串，绝不能枚举。这直接否决"枚举实现"。

## 落地：从形式结论到代码

### 单线求解：DP 而非枚举

**形式依据**：$\mathcal{L}(\rho,n)$ 是正则语言，成员判定与**前缀可行性**可用线性 DP 完成。要回答"该行第 $i$ 格在 $\mathcal{S}$ 投影中能否为 1/0"，等价于"是否存在一个串 $x \in \mathcal{L}$ 使 $x_i=1$"。

标准做法：维护 DP 状态 `dp[i][j]` = 处理到第 $i$ 格、已放置前 $j$ 个块时是否可行（含转移考虑块间白格），再**反向 DP** 得 `rdp`。某格在位置 $i$ 能为 1，当且仅当存在 $j$ 使"该格属于第 $j$ 块"的前向+后向路径同时可行。复杂度 $O(n \cdot k)$。

- **代码建议**：三值结果存 `uint8_t`（0/1/2=?, 便于 SIMD 与位运算）；每行/列各跑双向 DP；只写回"确定为某值"的格。可指回：算子 $F$ 单调收缩 + DP 完备枚举了该线的所有合法串的投影，故**不漏解**。
- **避免**：状态里不要存"位置 i 处在第 j 块内的偏移量"为三维——用 $O(nk)$ 的"块起点/终点可行性"二维即可，反例 6 要求的线性性由它保证。

### 传播到不动点

```
repeat until no change or conflict:
    for each row:  line_solve(row)
    for each col:  line_solve(col)
    if any cell assigned both 0 and 1: return CONFLICT
if all cells decided: return SOLVED (candidate)
```

- **架构建议**：`line_solve` 只返回 `{new_assignments, conflict?}`，**纯函数**，不直接改网格；由外层调度器统一合并。这样"冲突只在合并时检测"成为唯一真源，消掉交叉论证里点的"分支可解性 vs 谜题可解性"混淆——调度器知道自己在根还是分支。可指回视角 A 的单调收缩。
- **可观测不变量**：断言 `合并后 D 的每个已确定格在原 D 中都合法`（保解性）——生产环境开断言，测试环境用它抓回归。

### 回溯与分支选择

- **分支策略**：优先选**信息量最大**的 `?` 格——形式上选使两侧子问题 $\max(|D_{\text{子}}|)$ 更小的格，实践上用"所在行/列线索最长"或"行向/列向 DP 计数最小可行性分数"启发。这是纯经验性备注，指不回严格形式结论。
- **解数限制**：若只需一解，第一次 `SOLVED` 即停；若要判多解，找到两解即停（比枚举所有 $\mathcal{S}$ 便宜）。可指回：目标是判定 $|\mathcal{S}|$ 是否 $>1$，不是构造全部。
- **无解时**：根节点 `CONFLICT` 才是"谜题无解"；分支 `CONFLICT` 只是"该假设非法"。两者对应不同返回码，别合并。

### 复杂度取舍

- 单次传播 $O((H+W)\cdot n\cdot k)$；实际谜题分支因子常 $\le 2$ 且深度浅，整体近线性。
- 若要稳妥处理大规模谜题，`[另一解]` 换 **ILP**（每行块起点为整数变量 + 排序约束 + 覆盖约束，用 HiGHS/Gurobi），一次求解、天然处理多解（`SolCount`）；代价是整数变量数 $O(\sum k)$ 需大 M 线性化，且失去"传播进度"的可解释性。选择准则：交互式解题器用 CSP（能可视化传播）；离线批量/难例用 ILP。

## 独立校验

- **反向代入**：把任一 `SOLVED` 结果按线索独立校验（逐行逐列比对 $\mathcal{L}$）= 后置条件，必过；不过则传播有 bug（常见于 $k=0$ 越界）。
- **极小穷举对照**：对 $H,W \le 4$ 的所有线索组合，用暴力枚举 $G$ 结果对照解题器输出，作为测试夹具——覆盖边界 1–5。
- **第二路径**：对随机中规模谜题用 ILP 结果交叉比对 CSP 结果的**可解性判定**（不比对具体解，多解时二者可不同）。
- **已知难例**：拿来已发表的"需深层回溯"nonogram 作回归，衡量剪枝是否退化。拟合不上（例如解题器报无解而参考答案有解）→ 标 `[需验证]`，优先怀疑交叉论证里的根/分支混淆与空线索处理。

## 一句话实现骨架

三值网格 + 每线 $O(nk)$ 双向 DP 求投影 + 单调收缩迭代到不动点 + 分支回溯，根冲突 = 无解，二次 SAT = 多解。这是**正确性有形式依托、复杂度可由边界反例约束**的最小可行架构。
